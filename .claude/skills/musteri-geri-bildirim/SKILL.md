# Müşteri geri bildirimi (TASLAK)

- Kayıt biçimi `ARAMA_KAYITLARI.md` ile aynıdır: tarih, parça, firma, site değeri, eklenti değeri, sonuç, onay.
- "Yanlış" bildirimi gelirse KONTROL_TABLOSU durumu BEKLİYOR olur.
- Onay kullanıcıdan alınmadan "doğru" kabul edilmez.
